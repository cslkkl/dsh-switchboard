# .agents/notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

## 本目录约束

- 每篇第 3 行必须是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 必须跟指针行；`已归档` / `已否决` 必须跟一句话理由。
- 归档就地标记，不建 `archived/` 子目录。
- 不建索引文件；组织方式与查询路径见 [README.md](README.md)。
- 决策类必须写「替代方案」；依据类可省略，但应写「支撑的决策」指针。
- 决策类命名 `YYYY-MM-DD-<主题>`；依据类可省日期。
- 活文档与记录分离：描述「现在是什么」写进 [../../docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)；「当时为什么」写在这里。
